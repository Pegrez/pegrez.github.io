# Mars Outpost (Arpeba Rangers)

Our game about surviving on Mars for 6 months (178 sols) with a crew of 4:

* **Mateo Sheinbaum** (Engineer)
* **Xavier Netanyahu** (Geologist)
* **Grace Arpeba** (Botanist)
* **Adrian Salido** (Doctor)

## Controls

* **WASD** - Move around / drive the rover
* **E** - Interact (repair modules, plant crops, drill ice, collect rock samples)
* **R** - Scan for underground ice with radar (outside)
* **V** - Get in/out of the rover
* **C** - Switch crew member (inside the habitat)
* **B** - Bring a crewmate outside as your EVA buddy
* **G** - Turn the fuel plant on/off
* **P** - 3D-print a spare part (inside)
* **U** - Upgrade habitat insulation
* **1-5** - Change power modes for O2, Reactor, Grow Lights, Shield, and Heaters
* **H** - Show controls help

## How to run it

If you just want to play the game without installing Node.js, open `Mars Outpost Arpeba.html` in any browser.

To run the code in dev mode:

```bash
npm install
npm run dev
```
